# TCC 4SIS: TourMap

**Análise de sentimentos em avaliações turísticas em português brasileiro: comparação de modelos e abordagem híbrida neural-léxica.**

A pesquisa compara três formas de classificar o sentimento de avaliações turísticas escritas em português (um modelo treinado em inglês, um modelo multilíngue e uma lista de palavras) e propõe um método híbrido que usa a lista como segunda opinião quando o modelo tem pouca confiança. O ambiente de teste é a TourMap, uma plataforma web de turismo urbano.

O código da plataforma, a infraestrutura e o kit de avaliação (frases, rótulos, planilhas de rotulagem e scripts) estão em [`tourmap/`](tourmap/). Instruções de execução: [tourmap/README.md](tourmap/README.md).
